# Pureprofits Trading Journal

A live-updating trade log, P&L dashboard, and risk plan I use to track my day trading account.

**View it here:** https://nish2320-dev.github.io/pureprofits-trading/

## What this is

- **Overview** — current equity, total P&L, win rate, profit factor, max drawdown, and an equity curve
- **Trade Log** — every trade with entry/exit, P&L, and notes
- **Monthly Report** — performance summary by month
- **Risk Plan** — the rules I trade by (risk per trade, max daily/weekly loss limits)

## About this copy

The version on GitHub Pages is a **static snapshot** — it shows the account data as of the last time I published it here. It's not a live feed and has no backend, so nothing entered on this page (if you try the Add Trade form) is saved anywhere.

I update this snapshot periodically by regenerating the page from my live journal and pushing the change.

## Disclaimer

This is a personal trading journal for my own account. Nothing here is financial advice, and the risk-management percentages in the Risk Plan tab are a personal template, not a recommendation for anyone else's account.
